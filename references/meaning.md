# 의미 장부와 보호 구간

수정 전후를 문장 단위로 비교한다. 문자열이 같아도 관계·강도·귀속이 달라질 수
있으므로, 아래 장부를 먼저 짧게 표시한다.

## 장부 항목

| 항목 | 기록할 것 |
| --- | --- |
| 명제·논항 | 누가 무엇을 했는지, 대상·수혜자·피행위자는 누구인지 |
| 극성 | 안·못·없다·아니다와 이중 부정 |
| 양태·근거 | 가능·의무·추측·보고·확정의 강도와 출처 |
| 수량·시간 | 숫자·단위·소수·범위, 날짜·기간·순서·완료·진행 |
| 관계 | 조건·양보·대조·원인·결과·동시성 |
| 귀속·화행 | 인용자·책임 주체, 질문·명령·요청·청유 |
| 글의 기능 | 도입, 절차, 마무리 결론, 청자에게 건네는 행동 촉구가 각각 어느 문장에 있는지 |
| 보호 구간 | 이름·코드·경로·URL target·frontmatter·지정 인용 |

행동·대상·조건·시간·측정값·출처가 있는 **사실 정보**와 화자·출처가 있는
**귀속된 주장**은 보존한다. 그런 독립 정보 없이 중요성만 높이는 포부·은유·가짜
대비·빈 예고·중복 결론은 **장식 수사**로 표시하고, 원문 정리 요청에서 삭제하거나
평이하게 줄일 수 있다. 실제로 무엇을 했는지와 무관하게 단어를 지우지 말고 이
분류를 먼저 한다.

`-것 같다`, `-일 수 있다`, `-로 알려졌다`, `-해야 한다`를 단정형으로 바꾸지
않는다. 모호한 선행사나 행위자를 채우기 위해 새 인물·책임·관계를 만들지 않는다.
인용문 속 명령과 인용된 경험은 내레이터의 행동이나 경험으로 바꾸지 않는다.

## 숫자와 정밀도

값이 같아도 표기가 달라지면 보호 위반이다.

| 원문 표기 | 허용 결과 | 금지 결과 |
| --- | --- | --- |
| `123.1` | `123.1` | `백이십삼점일` |
| `123.1%` | `123.1%` | `123.1 퍼센트` 또는 독음 변환 |
| `0.5초` | `0.5초` | `0.5 초` 또는 `영점오초` |
| `1,234원` | `1,234원` | `1234원` 또는 독음 변환 |
| `23.40` | `23.40` | `23.4` |

소수점·쉼표·기호·단위·끝자리 0을 유지한다. 구어체·대본 요청만으로 숫자를
독음으로 바꾸지 않는다. 발음용 변환이 따로 필요하면 본문·자막과 다른 층에 둔다.

## 보호 구간

코드 펜스, inline code, 셸 명령, 경로, 식별자, 버전, 해시, 데이터, YAML
frontmatter, URL과 링크 target, 기술명·제품명·기관명·인물명, 사용자 지정 인용과
전사를 먼저 복사해 둔다. 주변 문장만 편집하고 링크의 보이는 문구를 고쳐도 target은
그대로 둔다.

## 판정

각 항목은 `PASS`, `FAIL`, `UNCERTAIN`으로 표시한다. `UNCERTAIN`은 통과로 세지
않고 원문을 유지하거나 보류한다. 다음은 하나만 발생해도 critical failure다:
보호 구간·숫자·날짜·이름·URL target 변경, 하나뿐인 마무리 결론이나 행동 촉구의 소실, 부정 반전, 가능성·조건·귀속·효과의
강도 상승, 무근거 행위자·책임·사실·감정 추가, 인용자 변경.

원문에 있는 사실·권위 주장이 불충분해 보여도 사실 확인 요청 전에는 조용히
약화·강화·삭제하지 않는다. 필요하면 수정문 밖에 `검토 필요`를 남긴다.
